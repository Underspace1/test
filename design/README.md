# Maquettes

Deux captures **autonomes** de la page (DOM rendu, CSS et avatar intégrés, sans JavaScript) :

- `maquette-mobile.html` — 390 × 844
- `maquette-desktop.html` — 1280 × 900

Pour les importer dans Figma : ouvre le fichier dans Chrome puis utilise l'[extension Figma](https://help.figma.com/hc/en-us/articles/9067379354135-Figma-Chrome-extension) (« Capture to Figma »), ou le plugin *html.to.design*. Le fond fluide WebGL est remplacé par un dégradé statique.

Ces fichiers sont régénérés à la main ; la source de vérité reste `profile.html` + `config.js`.
