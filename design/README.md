# Maquettes

## Aperçus autonomes de toutes les pages

Générés par capture du DOM rendu (CSS, avatar et captures intégrés, scripts retirés). À ouvrir directement dans un navigateur, aucun serveur nécessaire.

- `preview-accueil.html` / `.png` — page d’accueil
- `preview-profil.html` / `.png` — profil (desktop)
- `preview-profil-mobile.html` / `.png` — profil (mobile 390 px)
- `preview-dashboard.html` / `.png` / `-complet.png` — dashboard

Les iframes (aperçu en direct) sont remplacées par une capture du profil mobile.
